## 4. 已修复：结果不可复现（这条差点毁掉所有结论）

### 4.1 现象

同一份数据、同一参数，连续两次跑出：

| 次数 | 总收益 | 交易数 |
|---|---|---|
| 第 1 次 | +87.5% | 847 |
| 第 2 次 | +71.4% | 836 |
| 第 3 次 | +75.2% | 835 |

只有 `composite_ic6` 不稳定，其他 5 个策略完全一致。

### 4.2 根因

`engine.run()` 里给每日信号排序只用了 score：

```python
sig[d].sort(key=lambda x: -x[1])     # ← 错误
```

多因子合成的 score 是"权重和"，**大量信号分数完全相同**（例如 0.278+0.256=0.534）。
Python 的 sort 是稳定的，同分时保持原始顺序 —— 而原始顺序来自上游
`group_by(["symbol","date"])`，**Polars 不保证 group_by 的输出顺序**。

于是：**每天第 6 个及以后的信号被 `max_positions` 拒掉，拒谁取决于同分的先后 → 结果随运行而变。**

### 4.3 修复

```python
sig[d].sort(key=lambda x: (-x[1], x[0]))   # score 降序，symbol 字典序做 tiebreaker
```

验证：同一 hits 连跑 3 次完全一致（193,410.92 / 842 笔 / 拒单 2074），
跨进程跑两次热力图也完全一致。

### 4.4 修复后的确定数字（2015-2026，11 年）

| 策略 | 总收益 | 年化 | 回撤 | 夏普 | 交易 |
|---|---|---|---|---|---|
| 急跌反弹 −18%/12%/5天 | +53.2% | +3.7% | **−7.3%** | **0.82** | 171 |
| 急跌反弹 −12%/8%/20天 | +60.5% | +4.2% | −23.0% | 0.41 | 369 |
| **合成 IC6** | **+93.4%** | +6.2% | −38.3% | 0.40 | 842 |
| 52周新高 | +30.7% | +2.3% | −51.5% | 0.22 | 1287 |
| RSI超卖 | +5.5% | +0.5% | −38.0% | 0.10 | 1154 |
| 均值回归 | −1.7% | −0.2% | −43.0% | 0.06 | 941 |

**教训**：回测引擎里任何"排序 + 数量上限"的组合，都必须有确定性 tiebreaker。
否则你会得到一个"看起来在跑、其实每次都不一样"的系统——而且很难发现，因为
单个策略（分数唯一）完全正常，只有多因子合成才暴露。

### 4.2 其他限制

- 只有日线，30 分钟未实现（数据源限制）
- 盘中撮合是保守假设（涨停开盘不买）
- 样本仍是"今天还活着的 700 只"，有幸存者偏差
- 1997-2005 段虽然数据可用，但涨跌停制度 1996-12 才建立，规则不完全一致
