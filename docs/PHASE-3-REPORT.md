## 4. 最重要的发现：信号统计 ≠ 账户收益

同一个策略，两种口径的结果方向完全相反：

| 策略 | 信号统计（旧） | 账户回测（新） |
|---|---|---|
| 急跌反弹 | B1 **+1.07%/日**，IC +0.0223 | 2.5 年 **−16.29%** |
| 合成 IC6 | TopN **+1.54%/日** | 2.5 年 **+22.73%** |

差异来源，逐条可解释：

1. **仓位约束**：信号统计假设每只信号都买；账户只有 5 个仓位，拒单 93~449 次
2. **交易成本**：189 笔卖出 → 手续费 3,155 元（3.2% 本金）
3. **止损打断**：8% 止损把很多"信号后第 2~3 日才兑现"的票提前砍掉，胜率从 58% 掉到 26.6%
4. **持仓期**：信号统计是"次日买次日卖"，账户是平均持有 11~12 天

**结论**：任务书要求"旧回测标记为信号表现分析"是对的——两者不是同一个东西，
用信号统计的收益去预期账户收益，会高估一个数量级。

## 6. 已知限制（不掩盖）

1. **只有日线**：`period` 字段已预留 `D1/M30/combo`，但 M30 未实现
2. **盘中撮合是保守假设**：只有 OHLC，无法还原订单队列；涨停开盘一律视为买不进
3. **滑点用固定 bp**：没有按流动性/波动动态调整
4. **没有基准对比**：`excess_return` 需要指数数据，暂未接入
5. **收益率曲线未剔除未平仓浮盈波动**：期末仍有持仓，`unrealized_pnl` 单独列示
