## 补充 1：基准（不能只用沪深300）

V1.1 说「基准至少选择一个与策略适用范围相匹配的宽基指数」。当前只有沪深300 收盘价。

平台突破选出的多为**中小盘**，用沪深300 会系统性高估超额。

### 三层基准，缺一不可

| 层级 | 定义 | 用途 | 现状 |
|---|---|---|---|
| **B1 全市场等权** | 每日全市场个股等权平均收益累乘 | 最公平的对照（同一股票池） | ✅ 可算 |
| **B2 同市值分组等权** | 按流通市值分 5 组，取信号所在组的等权 | 剔除「小盘股整体跑赢」的影响 | ⚠️ 需市值数据 |
| **B3 宽基指数** | 沪深300 / 中证1000 / 创业板指 | 对外汇报用 | ⚠️ 只有沪深300 |

### 强制要求

**主结论必须用 B1（全市场等权），不能用 B3。**

B3 只在「对外沟通」时提及，且必须注明「本策略偏中小盘，沪深300 不是合适基准」。

**B2 在补齐市值数据后补做**；补齐前在报告里标注「未做市值中性化」。

## 补充 2：ST 与上市日期（当前数据做不到，给替代方案）

V1.1 要求「排除 ST、上市时间不足 60 个交易日」。这两个条件当前都缺数据。

### ST 的替代方案

```
现状：symbol_names.json 只有当前名称，无历史
      （"ST 金鸿" 能识别，但它 2023 年是不是 ST 查不到）

替代 A（推荐）：价格 + 成交额双重代理
  日均收盘价 < 6 元  AND  日均成交额 < 5000 万
  → 标记为「疑似 ST / 壳股」，单独统计，不直接剔除

替代 B（更保守）：直接不筛
  把 ST 影响交给「最小价格过滤」（price >= 3 元）
```

**采用替代 A，但把它做成可开关的过滤器**，报告里单独给「含 ST 代理」和「不含」两组数字。

### 上市日期的替代方案

```
现状：没有上市日期字段

替代：用该股票的首根 K 线日期
  bars_available = 截至 T 日的 K 线数
  条件：bars_available >= 60

局限（必须写进报告）：
  · 长期停牌后复牌的票会被误判为次新股
  · 2021-05 之前上市的票无法判断真实上市日期
```

## 补充 3：信号数量控制（V1.1 完全没提，但决定回测是否有效）

### 问题

平台突破 61,224 个信号 / 1,335 个交易日 = **平均每天 46 个**。

10 万本金、单票最大 25%（2.5 万）、每笔风险 1%（1000 元）—— **同时最多能持 4-8 只**。

**如果不控信号量，回测等于「从 6 万个信号里随机抽 500 个」，结论没有统计意义。**

这正是之前 5 个策略被停用的原因（被拒 130 万次）。

### 强制规则

```
每日选股上限  MAX_PER_DAY = 5
最大持仓只数  MAX_POSITIONS = 5
单票最大占比  MAX_POSITION_PCT = 25%
```

### 排序规则（必须固定，不能事后选）

按以下优先级排序，取前 5：

```
1. 突破幅度降序        (close - 平台上沿) / 平台上沿
2. 平台持续时间降序    平台长度（天数）
3. 平台振幅升序        (上沿 - 下沿) / 下沿
```

**这个排序规则本身要作为实验变量之一**，跑三组：
```
S1  只按突破幅度
S2  只按平台长度
S3  按振幅（越窄越优先）
```

对比哪组选出的票更好。

### 拒单要记录

回测必须输出：
```
每日信号数分布（中位 / 90 分位 / 最大）
被 max_per_day 拒掉的数量
被 max_positions 拒掉的数量
```

**如果「被拒 / 总信号」> 50%，这个回测可信度存疑，要在报告里标注。**

## 补充 4：方案 B 的卖出时点（V1.1 有歧义，定死）

V1.1 原文：

> B组：最多持有 5 个交易日，第 5 日收盘产生退出信号，下一交易日执行。

### 定死为

```
T 日     突破信号
T+1 日   开盘买入（成本 = open[T+1]）
T+5 日   收盘产生退出信号
T+6 日   开盘卖出（成交价 = open[T+6]）

账单层面持有天数 = 5 个交易日（T+1 到 T+5 收盘）
实际资金占用 = T+1 开盘 到 T+6 开盘（含一个隔夜）
```

### 统计口径分离（重要）

报告里必须区分两种收益：

```
策略收益 = open[T+6] / open[T+1] - 1     ← 实际能拿到的
信号收益 = close[T+5] / open[T+1] - 1    ← 剔掉隔夜跳空的"纯持有收益"
```

**两者之差 = 第 5 天到第 6 天的隔夜跳空。** 这个差值本身是有信息量的（如果系统性为负，说明持有到第 5 天该卖）。

### 三种方案的退出价定义

| 方案 | 卖出信号 | 卖出价 |
|---|---|---|
| A 跌破10日线 | T 日收盘 < MA10(T) | open[T+1] |
| B 固定5日 | 固定 T+5 | open[T+6] |
| C 混合 | min(跌破10日线, T+5) 先到者 | 信号次日 open |

## 补充 5：平台识别的可配置定义（V1.1 说必须明确，给出具体公式）

V1.1 说「平台识别规则必须明确、可配置、可回测」，但没给公式。这里给四个候选，**全部实现，全部测**。

### 定义 P1：振幅法（最简单）

```
平台窗口 [T-N, T-1]（不含 T 日，绝不泄漏）
上沿 = max(high[T-N .. T-1])
下沿 = min(low[T-N .. T-1])
振幅 = (上沿 - 下沿) / 下沿

平台成立条件：振幅 < R
突破条件：close[T] > 上沿
```

参数：`N ∈ {20, 40, 60}`，`R ∈ {0.10, 0.15, 0.20, 0.25}`

### 定义 P2：ATR 收敛法

```
ATR20[T] = mean(high-low, 20)
平台成立条件：ATR20[T-1] / close[T-1] < A
             AND ATR20[T-1] / ATR20[T-20] < 0.8   （波动在收敛）
突破条件：close[T] > max(high[T-N .. T-1])
```

参数：`N ∈ {20, 40}`，`A ∈ {0.02, 0.03}`

### 定义 P3：布林带收口法

```
带宽 = (MA20 + 2σ20 - (MA20 - 2σ20)) / MA20 = 4σ20 / MA20
平台成立条件：带宽[T-1] 在过去 250 日处于最低 20% 分位
突破条件：close[T] > MA20[T] + 1σ20[T]
```

### 定义 P4：回归斜率法

```
对 close[T-N .. T-1] 做线性回归
平台成立条件：|slope| / mean(close) < 0.001   AND   R² < 0.5
突破条件：close[T] > max(close[T-N .. T-1])
```

### 实验设计

```
4 个定义 × 各自参数网格，共 4 × 8 = 32 组
每组跑：样本内（2021-2023）+ 样本外（2024-2026）
先看样本内排名，再看样本外是否一致
```

**如果四个定义里只有 P1 有效，说明结论依赖特定定义，可信度下降。**

## 补充 6：过滤器开关矩阵（V1.1 要求，给出具体清单）

V1.1 要求「过滤条件应支持单独开关」。给出七个开关：

| 编号 | 过滤器 | 公式 | 默认 |
|---|---|---|---|
| F1 | 站上 MA20 | close[T] > MA20[T] | 开 |
| F2 | MA20 上升 | MA20[T] > MA20[T-5] | 开 |
| F3 | 量能放大 | volume[T] > mean(volume[T-5..T-1]) × 1.5 | **实验变量** |
| F4 | 不过度追高 | close[T] < MA20[T] × 1.15 | 开 |
| F5 | 排除 ST 代理 | 见补充 2 | 开 |
| F6 | 上市满 60 日 | bars_available >= 60 | 开 |
| F7 | 最小价格 | close[T] >= 3.0 | 开 |

### 实验矩阵（不是 2^7 = 128 组，太多）

按「逐个添加」跑 8 组：

```
G0  无过滤（基线）
G1  +F1
G2  +F1+F2
G3  +F1+F2+F3      ← 这就是 V1.1 的 B 组
G4  +F1+F2+F4
G5  +F1+F2+F4+F5
G6  +F1+F2+F4+F5+F6
G7  全部
```

**对比 G0 → G7，看每一步的边际贡献**。如果加某个过滤器后变差，说明这个过滤器有害。

## 补充 7：参数网格必须预先定死（防止边跑边调）

V1.1 说「不允许反复调整参数直到得到漂亮结果」。要让这条可执行，**参数网格必须在跑之前写进配置文件**。

```json
{
  "platform": {
    "definitions": ["P1", "P2", "P3", "P4"],
    "N": [20, 40, 60],
    "R": [0.10, 0.15, 0.20, 0.25]
  },
  "filters": ["F1", "F2", "F3", "F4", "F5", "F6", "F7"],
  "exits": ["A", "B", "C"],
  "sort": ["S1", "S2", "S3"],
  "risk_pct": 0.01,
  "max_positions": 5,
  "max_per_day": 5,
  "init_cash": 100000
}
```

**跑完一轮（约 4 × 8 × 8 × 3 × 3 = 2,304 组？太多，见下）**

实际按分层做，不是笛卡尔积：

```
第一轮  定义比较：4 个定义 × 默认参数 = 4 组
第二轮  参数敏感性：胜出的定义 × 3N × 4R = 12 组
第三轮  过滤器：胜出参数 × G0-G7 = 8 组
第四轮  止盈：胜出配置 × A/B/C = 3 组
第五轮  排序：胜出配置 × S1/S2/S3 = 3 组
────────────────────────────────────────
合计 30 组，每组跑 2 次（样本内/外）= 60 次回测
```

**60 次 × 约 1 分钟 = 1 小时。可接受。**

## 补充 8：失败退出条件（V1.1 缺）

V1.1 写了「不允许反复调参数直到漂亮」，但没写**如果结果不好怎么办**。

### 硬性判定

跑完五轮实验后，按以下规则判定：

```
成立：
  样本外（2021-2023）超额 ≥ +0.20pp/笔
  AND 样本外交易数 ≥ 100
  AND 成本 ×1.5 后仍为正
  AND 不依赖单一年份（每年超额 ≥ -0.10pp）

存疑（可继续研究，不能实盘）：
  样本外超额在 0 ~ +0.20pp
  或 成本 ×1.5 后转负
  或 有明显依赖某一年

不成立（宣布放弃）：
  样本外超额 < 0
  或 样本外交易数 < 50（样本太少无法判断）
```

**一旦判定「不成立」，该策略从启用清单移除，报告里记录失败原因。**

## 补充 9：幸存者偏差（V1.1 提了要检查，给出方法）

当前数据只包含**今天还在交易的 4,786 只**。退市股、长期停牌的票不在里面。

**影响方向**：策略表现会被**高估**（因为退市股通常是跌得很惨的）。

### 检查方法

```
1. 统计：当前股票池里，2021 年就存在的有多少只？（已知 12 只）
   → 说明 99.7% 的票是 2022 年后才进池子的
   → 这个池子本身就是「2022 年后还活着」的选择

2. 如果有退市股清单，对比：
   同样的突破信号，在退市股上表现如何？

3. 当前做不到，报告里必须写：
   「本次回测存在幸存者偏差，实际收益应低于报告值 X%」
```

**X 的估算**：A 股 2021-2026 退市约 200 只，占 4.2%。假设退市股在退市前一年平均跌 50%，对整体收益的影响约 **-1 到 -2 个百分点/年**。

**报告里统一扣 1.5pp/年 作为保守修正。**

## 一句话总结这份补充

**V1.1 解决的是「怎么诚实地做研究」，这份补充解决的是「拿什么做、做到什么程度算数」。**

其中三条是硬约束，缺一条结论就不可信：

```
1. 数据必须补到 5 年（否则样本外验证是假的）
2. 必须控信号量（否则回测等于随机抽样）
3. 必须有失败判定规则（否则会一直调到"漂亮"为止）
```
